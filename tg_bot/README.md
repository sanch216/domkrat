# Telegram Bot Техподдержки (AI Support)

Этот бот предназначен для помощи пользователям дашборда "Домкрат" (симулятор смога Бишкека). Он работает на базе ИИ (OpenRouter) и отвечает на вопросы об интерфейсе. Если вопрос сложный, он перенаправляет к менеджеру.

## Требования
- Установленный Python и зависимости из `requirements.txt` (`aiogram`, `openai`, `python-dotenv`).
- Токен Telegram бота (от @BotFather).
- Токен OpenRouter (тот же, что и у бэкенда).

## Настройка
1. Открой файл `.env` в корне проекта (где лежит бэкенд) и добавь туда строку:
```env
TG_BOT_TOKEN="твой_токен_от_ботфазера"
```

## Запуск
Бот запускается отдельным скриптом (не вместе с FastAPI бэкендом).
```bash
# Находясь в корне проекта (где лежит .venv)
.\.venv\Scripts\python.exe domkrat\tg_bot\bot.py
```

## Как это работает
- Если пользователь спрашивает, как пользоваться картой, ТЭЦ, трафиком — бот читает `SYSTEM_PROMPT` и отвечает с помощью нейросети `deepseek-v4-flash`.
- Если бот не может помочь или пользователь пишет "у меня ничего не работает", "позови человека" — ИИ выдает кодовую фразу `CALL_MANAGER`, и бот перенаправляет пользователя к `@support_citybreaz`.
